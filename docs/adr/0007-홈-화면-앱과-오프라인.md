# 0007. 홈 화면 앱(PWA)과 오프라인, 이름은 Kitty Kang
- 상태: 채택
- 날짜: 2026-10-12 · 기록: 2026-10-24
- 출처: `MOBILE_PLAN.md` 2·4·8장

## 맥락
- 고양.시는 켜 두고 보는 곳인데, 웹이라 다시 들어오는 길이 귀찮다.
- 앱스토어는 "웹에 아이콘만 씌운 앱"을 거절한다. 네이티브 앱은 위젯·알림 같은 기능이 생길 때까지 미룬다.

## 결정
- **홈 화면에 추가하는 웹 앱(PWA)** 으로 다시 오는 길을 짧게 한다. 주소창 없이(`standalone`), 세로·가로 모두.
- **오프라인에서도 방이 열린다.** 단, **새 버전을 올렸는데 예전 화면이 보이면 안 된다:** 코드·데이터는 네트워크 먼저(실패할 때만 캐시), 그림은 캐시 먼저(캐시 이름에 배포 버전). 새 서비스 워커는 다음에 열 때 적용(켜 둔 화면이 갑자기 새로 고침되지 않게).
- **홈 화면 이름은 Kitty Kang**(한국어·영어 같은 이름). 아이콘을 누르면 만나는 건 강고양이 씨이기 때문.
- **사이트 이름은 그대로 고양.시**(탭 제목·도메인). 나중에 다른 콘텐츠가 들어오면 우산 이름이 된다.

## 결과
- 배포 때 `sw.js`의 버전을 커밋 해시로 바꾸는 단계가 `pages.yml`에 있다(보호된 파일).
- 오프라인을 지키므로 그림은 결국 전부 받아야 한다 → 처음 열 때 속도와 부딪힌다(0008).
- 네이티브 앱·웹 푸시·맥 화면보호기는 나중 안건(MOBILE_PLAN 9장).
