## 범위
- 만화방 꾸밈(사장님·책장·셔터)·고양.시 현관문 약도·책장 만화책은 **다음 지시서**. 이번엔 "읽을 수 있게"만: 뷰어, 회차 목록, 공개일, 통계, 원고를 올리는 도구.
- 작품 하나: 「쫄깃 소넷맛 치킨」(id `csf`, 연재 제목 「여전히 나는 기본값이다」). 작품이 늘어도 같은 틀(`web/manhwa/<작품>/…`).
- 고양.시 방(`web/index.html`·`web/js/`)은 건드리지 않는다. 만화방은 `web/manhwa/` 아래 따로 — 방의 시작 묶음(0008)에 섞이지 않게.

## 결정 (회의 2026-11-06)
- **회차 주소는 무작위 짧은 이름:** `goyang.si/manhwa/csf/<이름>/` (예 `k7q2m`, 소문자·숫자 5자, 헷갈리는 글자 0·o·1·l 뺌). 회차를 처음 올릴 때 도구가 한 번 뽑아 `episodes.json`에 고정 — 다시 만들어도 안 바뀜. 화면엔 "3화"로. 저장소에서 보이는 건 막지 않는다(구상 4장).
- **회차 정보는 `web/manhwa/csf/episodes.json` 하나:** 회차마다 `{ "no": 1, "slug": "k7q2m", "title": "…", "open": "2026-11-20", "pages": 12 }` 같은 모양(정확한 칸은 구현 때, 메모에). 작품 정보(제목·영어 풀이 `Chewy Sonnet-Flavored Chicken`·소개)도 같은 파일 머리에.
- **원고:** 회마다 여러 장. 원본은 `assets/manhwa/csf/<회차 번호>/01.png, 02.png…`(png·jpg 둘 다, git 무시).

## 요구사항
- [ ] **회차 도구** `tools/build_manhwa.py <작품> <회차 번호>`: 원본 장마다 위아래 바깥 여백·테두리를 잘라내고(색이 고른 줄을 찾아서, 안쪽 칸 테두리는 남김), 폭 1080px로 맞춰, 긴 장은 세로 조각(한 조각 최대 약 2000px)으로 `web/manhwa/csf/<이름>/NN.webp`. 처음이면 이름을 뽑아 `episodes.json`에 회차를 더함(공개일은 인자 `--open YYYY-MM-DD`, 없으면 오늘), 다시 돌리면 그림만 다시. `--check`는 episodes.json과 파일이 맞는지만 본다
- [ ] **회차 HTML:** 도구가 회차마다 `web/manhwa/csf/<이름>/index.html`을 만든다(같은 틀, 회차 정보만 다름). 공유 미리보기 `og:title`(「여전히 나는 기본값이다」 3화 — 제목)·`og:image`(그 화 첫 조각을 1200×630에 맞춘 것)·`og:description`. 목록 `web/manhwa/csf/index.html`도 같이
- [ ] **뷰어**(`web/manhwa/viewer.js`·`viewer.css`, 의존성 없음): 폰은 화면 너비 꽉, 데스크톱은 가운데 720px. 조각을 경계 없이 잇는다. 이미지는 보이기 직전에 불러오고(lazy), 끝 무렵 다음 화 첫 조각을 미리 받는다
- [ ] 위·아래 막대: 아래로 스크롤하면 숨고, 위로 올리거나 탭하면 나온다. 위 = 작품·회차·제목, 아래 = 이전 화 · 목록 · 다음 화. 얇은 진행 막대
- [ ] **이어 보기:** 읽은 위치를 기기에만 저장(localStorage, try/catch). 목록·회차에 다시 오면 "N화 이어 보기"
- [ ] 회차 끝: 다음 화 버튼(공개된 것만) + "고양.시로" 링크(지금은 `/`로 — 출입문·딸랑은 다음 지시서)
- [ ] **공개일:** 기준은 한국 시간 자정(`Asia/Seoul`). 목록에는 공개된 회차 + **다음 한 화만** "○월 ○일 공개"(누르지 못함), 나머지는 숨김. 공개 전 회차 주소로 직접 오면 원고를 불러오지 않고 "아…직…이…에…요…"(사장님 그림은 다음 지시서 — 지금은 글만, 한 글자씩 느리게)
- [ ] **언어:** 막대·목록·안내 글은 KO/EN(브라우저 언어, 고양.시와 같은 규칙). 본문은 한국어만 — 영어 방문자에겐 목록에 "Korean only"
- [ ] **통계:** 고양.시와 같은 GoatCounter(`goyangsi`). 회차 주소라 화별 조회는 자동. 이벤트: 들어온 길(직접 링크 / 목록 / 다음 화), 회차 끝까지 읽음, 다음 화 누름, 고양.시로 감
- [ ] **오프라인(0007):** 서비스 워커가 만화방 그림을 시작 묶음에 넣지 않게(방이 무거워지지 않게). 만화방 페이지는 온라인 우선, 한 번 본 회차 그림만 캐시(상한을 두고 오래된 것부터 지움)
- [ ] 회차가 없을 때도 목록이 깨지지 않게(만화방 열기 전 시험용 가짜 회차 1개로 확인하고 그 회차는 커밋하지 않음 — 또는 `episodes.json`을 빈 목록으로)
