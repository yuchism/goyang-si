## 범위
- 거실과 기지를 잇는다: 거실 → 기지(출동), 기지 → 거실(귀환). **새 그림 없음** — 코드로.

## 열쇠
- 책장 **초록 책**(`green`)의 발바닥이 은은하게 반짝인다. 그 자리를 누르면 출동, 책의 다른 자리는 전처럼 고양이책.
- 누르는 자리는 폰에서도 눌리게 44px 이상(화면 기준).
- **만득 씨가 집에 있거나 행사(생일·할로윈) 중이면** 반짝이지 않고, 눌러도 고양이책.
- 처음 세 번은 조금 더 밝게 반짝인다(이 기기에만 저장, 없으면 늘 보통).

## 출동 (4~5초, 그동안 다른 입력은 막음)
1. 비상등: 화면 가장자리가 붉게 두 번 깜박.
2. 쥐야쥐가 작은 코드 왕관을 쓰고 쥐구멍으로 쏙.
3. 강고양이 씨가 하던 걸 멈추고 쥐구멍 앞으로 → 머리부터 주르륵(쥐구멍 모양으로 잘라 냄), 꼬리 끝이 마지막.
4. 어항이 바닥을 스르륵 미끄러져 쥐구멍 쪽으로 사라짐(설명 없음).
5. 쥐구멍으로 줌인 → `/base/`. 기지는 입구에서 시작(기지 1의 스르륵 그대로).

## 귀환
- 기지 발바닥 → `/?from=base` → 거실: 쥐야쥐 → 강고양이 씨 순으로 쥐구멍에서 튀어나와 평소 자리로. 어항은 처음부터 제자리.
- 거실은 실제 시간대로 흘러가 있다(밤이면 밤).
