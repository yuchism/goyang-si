## 요구사항
- [x] **회차 도구** `tools/build_manhwa.py <작품> <회차 번호>`: 원본 장마다 위아래 바깥 여백·테두리를 잘라내고(색이 고른 줄을 찾아서, 안쪽 칸 테두리는 남김), 폭 1080px로 맞춰, 긴 장은 세로 조각(한 조각 최대 약 2000px)으로 `web/manhwa/csf/<이름>/NN.webp`. 처음이면 이름을 뽑아 `episodes.json`에 회차를 더함(공개일은 인자 `--open YYYY-MM-DD`, 없으면 오늘), 다시 돌리면 그림만 다시. `--check`는 episodes.json과 파일이 맞는지만 본다
- [x] **회차 HTML:** 도구가 회차마다 `web/manhwa/csf/<이름>/index.html`을 만든다(같은 틀, 회차 정보만 다름). 공유 미리보기 `og:title`(「여전히 나는 기본값이다」 3화 — 제목)·`og:image`(그 화 첫 조각을 1200×630에 맞춘 것)·`og:description`. 목록 `web/manhwa/csf/index.html`도 같이
- [x] **뷰어**(`web/manhwa/viewer.js`·`viewer.css`, 의존성 없음): 폰은 화면 너비 꽉, 데스크톱은 가운데 720px. 조각을 경계 없이 잇는다. 이미지는 보이기 직전에 불러오고(lazy), 끝 무렵 다음 화 첫 조각을 미리 받는다
- [x] 위·아래 막대: 아래로 스크롤하면 숨고, 위로 올리거나 탭하면 나온다. 위 = 작품·회차·제목, 아래 = 이전 화 · 목록 · 다음 화. 얇은 진행 막대
- [x] **이어 보기:** 읽은 위치를 기기에만 저장(localStorage, try/catch). 목록·회차에 다시 오면 "N화 이어 보기"
- [x] 회차 끝: 다음 화 버튼(공개된 것만) + "고양.시로" 링크(지금은 `/`로 — 출입문·딸랑은 다음 지시서)
- [x] **공개일:** 기준은 한국 시간 자정(`Asia/Seoul`). 목록에는 공개된 회차 + **다음 한 화만** "○월 ○일 공개"(누르지 못함), 나머지는 숨김. 공개 전 회차 주소로 직접 오면 원고를 불러오지 않고 "아…직…이…에…요…"(사장님 그림은 다음 지시서 — 지금은 글만, 한 글자씩 느리게)
- [x] **언어:** 막대·목록·안내 글은 KO/EN(브라우저 언어, 고양.시와 같은 규칙). 본문은 한국어만 — 영어 방문자에겐 목록에 "Korean only"
- [x] **통계:** 고양.시와 같은 GoatCounter(`goyangsi`). 회차 주소라 화별 조회는 자동. 이벤트: 들어온 길(직접 링크 / 목록 / 다음 화), 회차 끝까지 읽음, 다음 화 누름, 고양.시로 감
- [x] **오프라인(0007):** 서비스 워커가 만화방 그림을 시작 묶음에 넣지 않게(방이 무거워지지 않게). 만화방 페이지는 온라인 우선, 한 번 본 회차 그림만 캐시(상한을 두고 오래된 것부터 지움)
- [x] 회차가 없을 때도 목록이 깨지지 않게(만화방 열기 전 시험용 가짜 회차 1개로 확인하고 그 회차는 커밋하지 않음 — 또는 `episodes.json`을 빈 목록으로)
