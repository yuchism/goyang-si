# 0009. 미리보기 도구는 `?dev=1`일 때만
- 상태: 채택
- 날짜: 2026-10-12 · 기록: 2026-10-24
- 출처: `MOBILE_PLAN.md` 13장

## 맥락
- 미리보기 도구 버튼이 21개까지 늘었고 계속 는다. 폰에선 방을 가린다.
- 더 큰 문제: 방문자가 버튼 하나로 UFO·산타·마녀를 불러낼 수 있으면, 기다리다 우연히 보는 순간들이 시시해진다.

## 결정
- **방문자에게는 미리보기 도구를 보이지 않는다.**
- `?dev=1`로 들어오면 켜지고 **그 기기에서 기억한다**(`localStorage`, 실패해도 그 페이지에서는 켜짐). `?dev=0`으로 끈다.
- 묶음 정리·폰용 판은 하지 않는다. 테스트는 노트북에서. 버튼은 계속 더해도 된다.

## 결과
- 지시서의 "미리보기 도구에 버튼 추가"는 계속 유효하다(개발자용). 확인 항목은 `?dev=1`로 무엇을 눌러 보는지까지 적는다(AGENTS.md 3장).
- 화면 점검(`visual_check.js`)은 버튼을 코드로 누르므로 숨겨져 있어도 동작한다.
- 이 결정이 0004(놀이는 운 좋은 순간)와 세계관의 "기다리다 보는 방"을 지킨다.
