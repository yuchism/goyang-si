## 상태 → 연출 (상태 JSON 모양은 `docs/STATUS_JSON.md`)
- **검은 고양이:** `roles.review`나 `roles.image_check`가 busy → 돋보기 · `relay` → 펼친 두루마리 읽기(강고양이 씨가 내민 두루마리를 받은 차례) · 그 밖 → 꾸벅 졸기.
- **붓 고양이:** `roles.image`가 busy → 붓질 · 그림 검수에서 다시 그리기(`image_check` 뒤 `image`로 돌아옴)면 한숨 한 번 뒤 붓질 · 그 밖 → 꾸벅 졸기.
- **한도 대기**(`factory.limit`): 식구가 다 보물상자 앞에 줄 서서 꾸벅 — 강고양이 씨·검은 고양이·붓 고양이가 상자 왼쪽에 나란히(졸기 그림), 왕은 왕좌에서 졸기. 풀리면 제자리로.
- **밤:** 같은 연출.
- 동작 줄이기면 자세만 바뀜.
