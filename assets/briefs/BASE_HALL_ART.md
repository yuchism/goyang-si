## 4. 불빛 — 밤 색조를 위한 규칙

밤에는 코드가 그림 전체를 어둡게 하고, **불빛 자리에만 빛을 다시 얹는다**(자리는 받은 그림에서 재서 `scene.json`). 그래서:

- **CRT 화면**(단말기 책상, 회랑 캐비닛에 있다면 그것도)은 **초록(`#7FE8A0` 근처) 단색 면**, 둥근 모서리 네모. 화면 안에 글자·줄·반사 무늬 없음.
- **캐비닛 램프**는 **작은 단색 동그라미**(지름 약 10~16, 주황 `#FFB347`·초록·빨강), 줄지어 몇 알. 번짐(글로우)은 그리지 않는다 — 코드가 얹는다.
- **샹들리에 전구**는 따뜻한 노랑(`#FFD77A` 근처) 둥근 알, 번짐은 아주 옅게만.
- 천창 빛줄기는 아주 옅게(밤엔 코드가 지운 것처럼 어둡게 덮는다).
- 그림 전체는 **낮(밝은 실내)** 기준으로 그린다 — 샹들리에가 켜진 밝고 따뜻한 홀. 그림자를 짙게 그려 미리 어둡게 만들지 않는다.

**다듬기 (AI, 그림이 들어온 뒤):**
- 크기가 크면 `Image.LANCZOS`로 2000×1000에 줄인다. 비율이 다르면 가운데 기준으로 2:1만 맞춘다. 2000×1000보다 작게 오면 키우지 않는다(좌표는 비율로 읽는다).

- 받은 그림에서 실제 자리를 재서 **`web/base/scene.json`에 적는다**(코드에 숫자를 박지 않음): 상황판 안쪽 판 사각형, 쥐구멍 입구, 발바닥 판, 왕좌 앉는 자리, 검수 의자, 단말기 책상, 이젤 캔버스, 보물상자 받침, 천창 횃대, 환기구, 샹들리에 둘, 불빛 자리(CRT 화면·램프 묶음), 폰에서 처음 볼 곳(쥐구멍 → 왕좌). 지시서 좌표와 달라진 것은 이 지시서 상태 줄과 티켓 구현 메모에 남긴다.
- 기지 그림은 방의 `meta.json`(`build_meta.py`) 대상이 아니고, 서비스 워커 시작 묶음에 넣지 않는다(본 것만 따로 담김 — 만화방과 같은 규칙).
- 코드는 그림을 못 불러오면 짙은 바위색 바탕 + 코드 상황판 + 발바닥 판 단추만으로 장면을 보여 준다(거실로 가는 길은 그대로 누를 수 있게).
- AI가 검수 폴더에 `_overview.png`를 만든다: 바탕 위에 상황판 칸 예시(코드 그림)와 비움 자리 사각형을 얹은 합성 + 밤 색조 합성.
