# 0006. TV 편성 규칙: 블록을 쌓고, 조건은 프로그램이 든다
- 상태: 채택
- 날짜: 2026-10-14 · 기록: 2026-10-24
- 출처: `TV_SCHEDULE_PLAN.md` 4·7·11·13장, `web/r/tv/schedule.json`

## 맥락
- 처음 편성은 칸을 먼저 정하고 채우는 방식이라, 프로그램이 늘면 특집 표와 시각 규칙이 코드 곳곳에 쌓였다.
- 새 프로그램을 넣을 때 `programs.json` 한 곳만 고치면 끝나게 하고 싶었다.

## 결정
- **길이는 프로그램 자체에 있다**(`runtime`, 분). 편성은 프로그램 블록을 하루에 차례로 쌓는다. 쏠림은 프로그램별 `maxPerDay`로 막는다.
- **방영 조건은 프로그램이 직접 든다.** 토큰 배열, 같은 종류끼리 "또는", 다른 종류끼리 "그리고". **토큰은 한글**(사람이 직접 쓰는 데이터).
- **우선순위: 기간(특집) > 시각 고정 > 자유 편성.** 같은 등급이 같은 시각을 잡으면 `check_tv.mjs`가 경고.
- **주간 고정 + 3개월 개편.** 난수 씨앗 = 개편 시즌 + 요일(같은 시즌엔 매주 같은 요일 같은 편성). 3·6·9·12월 첫 월요일. 시즌 이름은 한국어 계절 / 영어 New Season.
- 빈틈은 짧은 프로(`short`) → 줄일 수 있는 프로(`flex`) → 화면 조정 순서로 채운다.
- **낮잠 정파:** 프로그램이 모자란 낮 시간은 방송을 쉰다. 처음엔 13~16시였고, 프로그램이 늘면서 줄였다. 지금은 13:55~14:30, 15:30~16:00 두 번(사이에 홈쇼핑). 정파는 `schedule.json`에 두고 개편 때 줄여 간다.

## 결과
- 새 프로그램 = `programs.json` + `i18n.js`, 코드 수정 없음(AGENTS.md 6장).
- 방송국에 속한 고정 칸(마감 뉴스·정파)은 `schedule.json`, 프로그램은 `programs.json`으로 나뉜다.
- 편성을 바꾸면 TV 회귀 기준이 달라지므로, 다시 뽑을 때는 승인을 받는다.
