# 크리스마스 광장 지붕 위 엘프 스프라이트 지시서 v1 (XMAS_PLAZA_ELF_ART)

## 0. 이야기

밤의 고양.시 광장. 가끔 건물 지붕 능선 위로 **작은 엘프 그림자**가 자루를 메고 총총 달려간다. 지붕 사이는 폴짝, 굴뚝 옆에서 잠깐 광장을 내려다보고, 눈 쌓인 지붕에서 가끔 **미끄덩** 엉덩방아를 찧고는 털고 일어나 다시 간다. 누군지는 설명하지 않는다.

화면에선 **그림자(남흑색 한 덩어리)로만** 보인다 — 코드가 칠한다. 그래서 이 그림은 **윤곽만으로 엘프인 게 읽혀야** 한다.

## 1. 생김새

- 작고 통통한 엘프(2~3등신). **뾰족 모자**(끝이 뒤로 휘어지고 끝에 방울), **뾰족 귀**(모자 옆으로 삐죽), 짧은 몸, 짧은 다리, 끝이 말린 신발.
- 등에 **불룩한 자루**(선물이 든 듯 울퉁불퉁, 어깨 위로 묶은 끝). 한 손으로 자루 끈을 잡는다.
- 실루엣 또렷하게: 모자 끝·귀·자루·신발 끝이 몸과 겹치지 않고 바깥으로 튀어나와 보이게. 팔다리 사이 틈이 보이게.
- 색은 아무거나(초록 옷·빨간 모자 같은 보통 엘프 색이면 좋다) — 코드가 덮어 칠한다. 화풍은 손님들과 같은 진한 갈색 굵은 외곽선 손그림.

## 2. 8칸 (모두 옆모습, **오른쪽을 보고**)

| 칸 | 동작 |
|---|---|
| ① | 달리기 — 왼발 앞 닿기 |
| ② | 달리기 — 두 발 다 뜬 순간(몸 앞으로 숙임) |
| ③ | 달리기 — 오른발 앞 닿기 |
| ④ | 달리기 — 두 발 다 뜬 순간 |
| ⑤ | **점프** — 공중, 다리 앞뒤로 쭉, 자루가 뒤로 들림 |
| ⑥ | **멈춰서 내려다보기** — 서서 몸을 살짝 앞으로, 고개 숙여 아래(오른쪽 아래)를 봄 |
| ⑦ | **미끄덩** — 앞발이 앞으로 쭉 미끄러지고 몸이 뒤로 젖혀짐, 두 팔 허우적, 자루가 위로 들림, 모자가 비뚤 |
| ⑧ | **엉덩방아** — 바닥에 털썩 주저앉음, 다리 앞으로, 자루가 옆에 툭, 모자가 얼굴로 흘러내림 |

- ①~④는 제자리 달리기(앞으로 나가는 건 코드). 일어나 털기는 코드가 ⑧ → ⑥ → 달리기로 잇는다.
- 왼쪽을 보는 그림은 그리지 않는다(코드가 뒤집는다).

## 3. 공통 규격

| 항목 | 값 |
|---|---|
| 시트 | **4096×512 한 장, 가로 8칸(칸마다 512×512)**, 칸 순서 ①~⑧ 왼쪽부터 |
| 배경 | 투명 |
| 발 기준선 | **y = 480**. ①③⑥⑧(⑧은 엉덩이)가 여기 닿음. ②④⑤⑦은 떠도 됨(⑤는 약 80px) |
| 키 | 모자 끝까지 약 **300px**(⑥ 서 있을 때). 모든 칸 같은 크기 |
| 칸 넘침 | 모자 끝·자루·발 끝까지 자기 칸 안에 |

**그리지 않는 것:** 그림자 칠하기, 지붕, 눈 튀기, 글자.
