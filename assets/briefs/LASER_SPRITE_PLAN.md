## 1. 한눈에

| 순서 | 파일 | 한 줄 | 바로 앞 그림 | 바로 뒤 그림 | 화면에 머무는 시간 |
|---:|---|---|---|---|---|
| 1 | `cat_wiggle_1` | 몸 낮추고 엉덩이를 **조금 위로** | `cat_stand` | `cat_wiggle_2` | 0.2초씩 번갈아 0.8~1.4초 |
| 2 | `cat_wiggle_2` | 같은 자세, 엉덩이를 **조금 아래로** | `cat_wiggle_1` | `cat_wiggle_1` 또는 `cat_run_1` | 〃 |
| 3 | `cat_pounce_1` | 뒷발로 튀어올라 **공중**, 몸 쭉 | `cat_stand` (또는 `cat_pawcheck_1`) | `cat_pounce_2` | 0.22초 |
| 4 | `cat_pounce_2` | 앞발 두 개로 바닥 **꾹**, 머리 낮게 | `cat_pounce_1` | `cat_pawcheck_1` | 0.22초 |
| 5 | `cat_pawcheck_1` | 앞발 하나 살짝 들고 **그 밑을 내려다봄** | `cat_pounce_2` | `cat_stand` / `cat_run_1` / `cat_pounce_1` | 0.9~1.3초 |
| 6 | `cat_wallreach_1` | 뒷발로 서서 앞발 둘 **벽에 짚고** 올려다봄 | `cat_stand` | `cat_stand` / `cat_run_1` | 점이 벽에 있는 동안 (최대 2.5초) |

새 그림의 앞뒤는 대부분 **`cat_stand`(서 있기)**, **`cat_run_1~6`(달리기)**다. 두 그림과 몸 크기·색·방향이 바로 이어져야 한다.

## 2. 놀이 전체 흐름 (어떤 그림 다음에 어떤 그림)

```
[식빵/잠]  cat_loaf_1 · cat_sleep_1
   │  (일어나기, 기존) cat_stretch → cat_sit_1
   ▼
cat_stand ──(점이 멀면)──▶ ★wiggle_1 ⇄ ★wiggle_2 ──▶ cat_run_1…6 (달리기)
   │                                                      │
   │◀──────────────── 점 근처에 도착 ───────────────────────┘
   │
   ├─(점이 바닥에서 멈춤)──▶ ★pounce_1 ─▶ ★pounce_2 ─▶ ★pawcheck_1 ──┐
   │                                                                  │
   │       ◀── 점이 그대로면 한 번 더 (pounce_1부터) ─────────────────┤
   │       ◀── 점이 움직이면 cat_stand → cat_run ─────────────────────┘
   │
   └─(점이 벽·창 위)──▶ ★wallreach_1 ──(점이 내려오면)──▶ cat_stand → cat_run
   
[끝] cat_stand → (앉기, 기존) cat_sit_1 → cat_sit_2 → cat_loaf_1   말풍선 😮‍💨
```

★ = 이번에 그릴 그림. 나머지는 이미 있다.

**연결 규칙 (코드가 하는 일)**
- 그림 안에서 고양이를 옮기지 않는다. 달리기·덮치기의 이동은 코드가 발 위치를 옮긴다.
- 덮치기(`pounce`)는 코드가 0.44초 동안 고양이를 점 쪽으로 약 1~1.5 몸길이 날려 보낸다. 앞 60%(=`pounce_1` 시간)에 날고, `pounce_2`에서 착지한다.
- 오른쪽으로 갈 때는 코드가 그림을 좌우로 뒤집는다. **모두 왼쪽을 보는 그림으로만** 그린다.

## 3. 공통 규격

| 항목 | 값 |
|---|---|
| 캔버스 | 정사각 512×512 이상 (원본은 1024 권장), **투명 배경** |
| 방향 | 왼쪽을 본다 (머리가 왼쪽, 꼬리가 오른쪽) |
| 기준점 | **발바닥 가운데 아래** = 바닥선. 모든 프레임의 바닥선 높이가 같게 |
| 여백 | 귀·꼬리·방울이 가장자리에 닿지 않게 사방 10% 이상 |
| 크기 | `cat_stand`와 같은 몸 크기. 머리 폭, 몸통 길이를 `cat_stand` 위에 겹쳐 맞춰 본다 |
| 선·색 | 기존과 같은 진한 갈색 외곽선(굵기 같게), 평평한 색면, 그림자 없음 (발밑 그림자는 코드가 그린다) |
| 파일 | 원본 `assets/sprites/cat-laser-<이름>-v1.png` → 웹용 `web/f/cat_<이름>.webp` |

**강고양이 씨 체크리스트 (매 장)** — 기존 그림과 하나라도 다르면 다시
- 크림색 몸, **머리 위 곱슬 털 뭉치**
- **오른쪽 눈(화면 기준) 둘레의 갈색 얼룩**, 등의 큰 갈색 얼룩
- 분홍 귀 안쪽, 반쯤 감긴 듯한 특유의 눈매 (놀랄 때만 동그랗게)
- **혀 살짝 내밀기**
- **주황 목줄 + 금색 방울**
- 꼬리: 크림색, **끝이 갈색**, 굵고 둥글게
- 발가락 끝 분홍 점

## 4. 프레임별 지시

### ★1·2 `cat_wiggle_1`, `cat_wiggle_2` — 엉덩이 씰룩 (덮치기 직전 준비)

**언제:** 점을 처음 봤는데 멀리 있을 때. `cat_stand`에서 바로 넘어오고, 끝나면 `cat_run_1`로 달려 나간다.

**자세**
- 앞쪽(머리·가슴)을 **바닥 가까이 낮춘다.** 턱이 바닥에서 몸 높이의 1/4 정도.
- 앞발 두 개는 가지런히 앞으로, 팔꿈치 접힘.
- 엉덩이는 **들려 있다**(앞보다 높게). 뒷발은 몸 아래로 모아 디딤.
- 꼬리는 낮게 뒤로 뻗고, 끝만 살짝 올라감.
- 눈은 **동그랗고 크게, 앞(왼쪽 아래 점)을 노려본다.** 귀는 앞으로 쫑긋. 혀는 넣거나 아주 조금.

**두 장의 차이 — 이것만 바뀐다** (실제 고양이는 엉덩이를 좌우로 흔들지만, 옆모습에서는 엉덩이가 살짝 오르내리는 것으로 보인다)
- `wiggle_1`: 엉덩이(몸 뒤쪽 끝)가 **조금 위로**(몸 높이의 5% 정도). 꼬리 끝이 위로.
- `wiggle_2`: 엉덩이가 **조금 아래로**. 꼬리 끝이 아래로. 뒷발 위치는 그대로.
- 머리·앞발·눈 위치는 **두 장이 완전히 같다** (겹쳤을 때 앞쪽 절반은 똑같아야 씰룩만 보인다).

**참고:** 지금 대신 쓰는 `cat_startle_3`(몸 낮춘 큰 눈)이 분위기는 가깝다. 그보다 엉덩이가 더 높고 앞이 더 낮게.

### ★3 `cat_pounce_1` — 튀어오름 (공중)

**언제:** 점 근처에서 점이 멈췄을 때. 앞은 `cat_stand`(가끔 `cat_pawcheck_1`에서 한 번 더), 뒤는 `cat_pounce_2`.

**자세**
- **뒷발로 막 박차고 올라 몸이 대각선으로 쭉 펴진 순간.** 머리가 앞(왼쪽) 위, 엉덩이가 뒤 아래.
- 앞발 두 개는 **앞으로 쭉 뻗어** 아래(착지할 곳)를 향함. 발바닥이 살짝 보임.
- 뒷발은 뒤로 뻗어 바닥에서 막 떨어짐.
- 꼬리는 뒤로 길게, 균형 잡듯 위로 휘어짐.
- 눈은 크게, 착지점(왼쪽 아래)을 봄. 귀는 뒤로 살짝 눕힘.

**바닥선 주의:** 몸 전체가 **바닥선보다 위에 떠 있다.** 뒷발 끝이 바닥선에서 몸 높이의 1/5쯤 떨어지게. 기준점(바닥선 가운데)은 다른 프레임과 같은 높이에 그대로 두고, 고양이만 위로 띄워 그린다.

### ★4 `cat_pounce_2` — 착지, 앞발로 꾹

**언제:** `cat_pounce_1` 바로 다음. 뒤는 `cat_pawcheck_1`.

**자세**
- 앞발 **두 개를 모아 바닥을 꾹 누른다.** 앞발 끝이 몸에서 가장 왼쪽.
- 머리는 앞발 바로 위로 **낮게 숙여** 앞발을 내려다봄.
- 엉덩이는 아직 조금 들려 있고 뒷발은 몸 아래로 막 착지.
- 꼬리는 착지 반동으로 위로 휘어짐.
- 눈은 크게, 앞발 사이를 봄. 입은 꾹 다물거나 혀 조금. 귀는 앞으로.

**참고:** 지금 대신 쓰는 `cat_stretch`(기지개)와 앞발 위치는 비슷하지만, 기지개처럼 늘어진 느낌이 아니라 **힘이 들어간** 느낌. 엉덩이를 기지개보다 낮게, 몸을 짧게.

### ★5 `cat_pawcheck_1` — 앞발 밑 확인 (이 놀이의 핵심 컷)

**언제:** `cat_pounce_2` 바로 다음. 1초 정도 머문 뒤 점이 움직이면 `cat_stand`→`cat_run_1`, 점이 그대로면 `cat_pounce_1`로 한 번 더. 이 그림이 보이는 동안 머리 위에 ❓ 말풍선이 자주 뜬다.

**자세**
- 네 발로 선 자세(`cat_stand`와 같은 높이)에서 **화면 쪽(앞에 보이는) 앞발 하나를 살짝 들어** 발바닥을 바닥에서 손가락 두어 마디만큼 띄운다.
- 머리를 숙이고 **고개를 살짝 기울여 그 들린 발 밑을 들여다본다.** 이 방의 개그는 여기서 나온다: "분명히 잡았는데?"
- 눈: 한쪽 눈이 반쯤 감긴 의심하는 눈, 시선은 발 밑. 입은 꾹 다물거나 혀 아주 조금.
- 귀: 하나는 앞, 하나는 옆으로 (갸웃).
- 꼬리: 낮게, 끝이 물음표처럼 살짝 말림.

**참고:** 지금 대신 쓰는 `cat_paw_2`(컵 밀기 준비)는 앞발은 들었지만 **눈이 앞을 본다.** 새 그림은 **눈과 머리가 아래(들린 발 밑)를 봐야** 한다. 이것만 맞으면 된다.

### ★6 `cat_wallreach_1` — 벽 짚고 올려다보기

**언제:** 점이 벽이나 창(바닥보다 위)에 올라갔을 때. 달려와서 `cat_stand`로 멈춘 다음 이 그림. 점이 내려오면 `cat_stand`, 다시 달리면 `cat_run_1`.

**자세**
- **뒷발 두 개로 선다**(옆모습). 몸이 거의 세로.
- 앞발 두 개를 **왼쪽 위로 뻗어 벽을 짚는다.** 앞발 끝이 그림의 가장 왼쪽·위쪽. (벽은 그리지 않는다 — 앞발이 평평한 면에 닿은 모양으로만)
- 머리는 젖혀 **위를 올려다본다.** 눈 동그랗게, 입 살짝 벌림.
- 꼬리는 바닥 쪽으로 내려 몸을 받치듯 뒤로.
- 뒷발 발바닥이 바닥선에 닿는다(기준점 = 뒷발 가운데).

**크기:** 서면 키가 커진다. 머리 위 곱슬 털까지 캔버스 안에 들어오게 여백을 넉넉히 (높이 기준 여백 12% 이상).
**참고:** 지금 대신 쓰는 `cat_lookup_3`은 네 발로 서서 고개만 듦. 새 그림은 **몸 전체가 일어선다.**

## 5. (선택) 탁자 위 레이저 포인터 `laser`

| 항목 | 값 |
|---|---|
| 파일 | `web/r/laser.webp`, 원본 512×256 정도, 투명 배경 |
| 모양 | 탁자 위에 **옆으로 누운** 작은 펜형 레이저 포인터. 몸통은 진회색, 끝(오른쪽)은 은색 금속, 몸통 위에 작은 빨간 단추 하나 |
| 방향 | 빛이 나오는 끝이 **오른쪽**. 살짝 기울어(왼쪽이 아주 조금 높게) 놓인 모양 |
| 하지 말 것 | 빛줄기·빨간 점은 그리지 않는다 (코드가 그린다). 브랜드 글자 없음 |
| 크기 | 방에서 폭 40 정도로 쓴다 (컵의 폭과 비슷) |

넣은 뒤에는 `objects.json`의 `laser.look`을 `"code:laser"`에서 `"laser"`로 바꾸고, 끝 불빛만 코드로 덧그린다(제가 맞춰 둠).

## 6. 넣는 순서

1. 원본을 `assets/sprites/`에 두고, 웹용으로 줄여 `web/f/cat_wiggle_1.webp` … 로 저장
2. `python3 tools/build_meta.py` → `web/f/meta.json`에 크기·기준점이 들어간다
3. 기준점 확인: 기본값은 그림 아래 가운데. `pounce_1`(공중)은 **고양이 아래 빈 공간까지 포함한 캔버스 아래 가운데**가 기준점이어야 한다(위 4장 ★3 참고)
4. `web/js/anim.js`의 `CLIP`에서 임시 이름을 바꾼다:

```js
wiggle:    { f: ['wiggle_1', 'wiggle_2'], fps: 5, loop: 1, base: 'stand' },
pounce:    { f: ['pounce_1', 'pounce_2'], fps: 4.5, base: 'stand' },
pawcheck:  { f: ['pawcheck_1'], fps: 1, base: 'stand' },
wallreach: { f: ['wallreach_1'], fps: 1, loop: 1, base: 'stand' },
```

5. 미리보기 도구 「레이저」로 확인: 서 있기 ↔ 새 그림이 바뀔 때 **몸이 튀거나 커졌다 작아지지 않는지**. 튀면 meta.json의 기준점(3·4번째 값)이나 크기 보정(5번째 값)을 조금 고친다

**한 장씩 먼저 넣어도 된다.** 효과가 큰 순서: `pawcheck_1` → `pounce_1·2` → `wiggle_1·2` → `wallreach_1`. 아직 없는 이름은 임시 그림을 그대로 쓰면 된다.
