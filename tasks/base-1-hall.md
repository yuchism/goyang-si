## 결정
### 배경 그림 (지시서 왕복으로 지시서를 쓰고 그림)
- 가로로 긴 장면 한 장(만화방 장면과 비슷한 비율, 크기는 지시서에서). **동굴 속 지하 궁궐 + 옛날 전산실:** 바위를 깎은 기둥·아치, 붉은 카펫(왼쪽 쥐구멍 입구 → 가운데 왕좌 단), 종유석 사이 크리스털 샹들리에, 금테. 양쪽 회랑에 램프 달린 대형 컴퓨터 캐비닛·테이프 릴·CRT 단말기.
- 가운데 **높은 왕좌 단**(왕좌는 비워 둠 — 쥐야쥐는 `base-2`), 그 뒤 **벽 전체를 상황판 자리로 비움**(어두운 판, 글자 없음).
- 자리만 마련: 단말기 책상(강고양이), 검수 의자, 이젤, 보물상자 자리, 천창(까치 횃대), 천장 환기구(만득 씨 말풍선), 쥐구멍 입구 옆 벽의 발바닥 판.
- **그림에 글자 없음.** 낮·밤 한 장, 밤은 코드 색조(샹들리에 어둡게, 단말기 불빛 남김).
- 자리 숫자(상황판 칸, 각 자리 좌표)는 장면 설정 한 곳(`web/base/scene.json`)에.

### 상황판 (코드)
- **공항식 넘김 전광판:** 글자판 칸이 바뀔 때 위아래로 촤라락 넘어감. 소리는 코드로 만든 짧은 딸깍 소리, 설정 책의 소리 켜기를 따른다. 동작 줄이기 설정이면 넘김 없이 바뀜.
- 화면 넷이 천천히 돈다(한 화면 약 12초 `초기값`): **지금**(진행 중 일·단계, `relay`면 "왕복 2/3", 제목 없으면 "비밀 작업 🐾") / **이번 주** / **누적 기록**(완료·무장애 ○일·까치 출동·그림·다시 그림·한 방 통과 %·왕복 평균·어명 반려·평균 걸린 날) / **최근 끝낸 일**.
- 상단 띠: "마지막 소식: 오늘·어제·며칠 전"(JSON `day`와 한국 날짜 비교).
- KO/EN 둘 다. 칸 수에 맞게 자르기.

### 상태 JSON 읽기
- 주소는 장면 설정에: `https://yuchism.github.io/goyang-status/status.json` (하네스가 3시간마다 올림, 2026-11-07 첫 게시 확인. 나중에 `status.goyang.si`로 바뀔 수 있음 — 설정 한 줄). 비어 있거나 읽기에 실패하면 **`web/base/demo.json`**(모든 단계가 한 번씩 나오는 예시)으로, 상단 띠에 "연습 화면".
- 믿지 않는 입력으로 다룸: 크기 상한, 모양 검사, 모르는 열쇠·`stage`는 무시, 글자는 `textContent`로만. 마지막으로 정상 받은 것을 기억(기기에만).
- 3시간 게시라 읽기도 드물게(페이지 열 때 + 30분마다 `초기값`).
- 모양은 goyang-hq `ideas/CAT_INC_IDEAS.md` 2-4장(`v`, `day`, `factory`, `roles`, `tasks[stage·round·title]`, `recent`, `stats`).

### 화면·둘러보기
- 넓은 화면은 장면 전체, 좁은 화면은 일부 + 가로 끌기(만화방과 같은 방식). 들어오면 쥐구멍 입구에서 왕좌까지 스르륵(만지면 멈춤, 동작 줄이기면 바로 왕좌).
- 쥐구멍 입구 옆 **발바닥 판**을 누르면 고양.시 거실로(`/?from=base`). 거실 쪽 귀환 장면은 `base-3`.
- 오프라인 지원은 만화방처럼(`sw.js`): 페이지는 네트워크 먼저, 그림은 담아 둠, 상태 JSON은 담지 않음(늘 새로).
- GoatCounter: 기지 방문(`base-visit`), 상황판 화면을 눌러 넘김(`base-board`, 방문당 한 번).
