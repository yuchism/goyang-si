# tasks/ — 할 일 파일(지시서) 쓰는 법

> 누가 써도 같은 모양으로: 사람, Claude, Codex, ChatGPT 어느 세션이든 이 문서대로 쓰면 고양이 사무실(하네스)이 티켓을 만든다.
> 하네스가 읽는 모양의 원본은 goyang-office `docs/PLAN_FORMAT.md`. 이 문서는 그 요약 + 이 저장소 관례.

## 흐름
1. 회의(논의·결정) → 이 폴더에 `tasks/작업명.md`를 쓴다(아래 틀).
2. 하네스에 맡길 준비가 되면 머리에 `- office: ready`를 넣고 `main`에 **커밋**한다(푸시는 안 해도 됨 — 하네스는 맥의 로컬 `main`을 읽음).
3. 하네스가 헤드쿼터에 일감을 열고 확정을 요청한다 → 주인이 `✅ 확정` → 티켓이 생김 → `✅ 구현 시작`.
- 하네스에 안 맡길 일은 `- office:` 줄을 넣지 않으면 된다(지금처럼 사람·AI가 직접).
- **`- office: ready`는 회의가 끝나고 주인이 확인한 뒤에만 넣는다.** 커밋하는 순간 하네스가 일감을 열 수 있고, 나중에 줄을 빼도 이미 연 일감은 멈추지 않는다(2026-11-01 TV 편성 #33).

## 틀
```markdown
# 제목 (티켓 제목이 됨)
- status: brief
- mode: needs-review            ← 사람 검수 필수 (auto면 구현 시작 승인을 건너뜀)
- office: ready                 ← 하네스에 맡김. 같은 값으로는 한 번만 — 다시 돌리려면 `ready 2`
- relay: brief                  ← (넣으면) 지시서 왕복: 일꾼(Claude)이 먼저 그림 지시서를 쓰고 검수(ChatGPT)와 최대 3번 주고받은 뒤 그림까지. 주인은 확정·시작과 사람 검수만
- implement: codex              ← (넣으면) 이 티켓만 ChatGPT(Codex)가 구현, 검수는 Claude. 없으면 Claude 구현·ChatGPT 검수
- brief: (그림 지시서 경로 또는 "그림 없음")
- related-adr: …
- 출처: 회의 YYYY-MM-DD

## 범위 / 결정 / 배경 …      ← 자유. 일꾼이 읽을 뿐 하네스는 안 봄 (여기 체크 줄은 완료 기준이 아님)

## 요구사항
- [ ] 무엇을 바꾸는지 (일꾼이 "했다"고 선언 → 검수자가 확인)

## 확인
- [ ] `node tools/check_….mjs` 통과
- [ ] 무엇 (사람): 무엇을 띄워서 무엇을 보는지   ← (사람)은 줄 어디에 있어도 사람 항목
- [ ] (참고) 막지 않는 메모

<!-- office:verify
- node tools/check_….mjs
-->                             ← 필수. 하네스가 샌드박스에서 직접 돌리는 명령(네트워크 없음). 없으면 비워 둔다

## 메모
- 날짜, 누가 썼는지, 구현하며 달라진 점
```

## 규칙 (하네스가 읽는 것)
- **완료 기준** = `## 요구사항`·`## 확인`·`## 완료 기준` 절의 `- [ ]` 줄만. 다른 절과 코드 울타리(```) 안은 읽지 않는다.
- **검사 블록**(`<!-- office:verify … -->`)이 없으면 티켓을 만들지 않는다. 명령이 없으면 빈 블록으로.
- **티켓 여러 개**: `## 티켓: 이름` 절마다 하나. 그 절의 `- [ ]` + 공통 절의 `- [ ]`. 절 안에 검사 블록이 있으면 그것, 없으면 공통 블록.
- **목록 묶음**(그림 배치 등): `## 할 일`(`{id}`·`{item}` 자리) + `## 완료 기준` + `## 목록`(줄 하나 = 티켓 하나) + 검사 블록.
- 커밋 전에 맥에서 확인: `npm run office -- plan:check tasks/작업명.md` (goyang-office 폴더에서) → 만들어질 티켓 미리 보기.
- 일꾼은 지시서의 `status`·메모를 고쳐도 되지만 `- office:` 줄은 건드리지 않는다.
- **끝난 지시서는 `- office: done`으로 바꾼다**(주인이 합칠 때, 또는 정리 커밋). `ready`가 남아 있으면 장부를 새로 만들 때(헤드쿼터 이사 등) 하네스가 다시 연다 — 2026-11-05 이사 때 7개.
