## 4. 그림 2·3 — 약도 광장 (`plaza-xmas` · `plaza-lot`)

**어디에:** 약도 빈 터 A(x 120~360 · y 160~400). 코드가 캔버스 아래 가운데 (256, 496)을 약도의 (240, 400)에 맞춰 약 0.47배(240×240)로 얹는다. 약도에서 폭 약 65px(폰)~125px(데스크톱). 「광장」 이름표 자리는 A 터 아래에 따로 비워 둔 곳이 없으므로 그림을 받은 뒤 약도 위에서 찍는다.

- 만화방 건물 그림(`shop-day.webp`)과 **같은 시점·같은 선 굵기**. 땅 선 y = 496.
- 낮도 밤도 아닌 그림(약도 바탕처럼). 해·달·강한 그림자 없음.
- **plaza-xmas:** 위에서 비스듬히 본 작은 광장 — 둥근 돌바닥 한가운데 트리(별·빨강·금 장식 공), 옆에 작은 회전목마 지붕. 큼직한 덩어리로.
- **plaza-lot:** 같은 자리·같은 크기의 빈 땅 + 낮은 나무 펜스(또는 줄무늬 공사 가림막) 둘레, 안에 흙더미·삽 하나 정도. 쓸쓸하지 않고 귀엽게.
- 두 그림의 땅 모양·크기·자리는 같게(코드가 갈아 끼운다).

## 5. 피할 것

- 글자·숫자 없음 — 간판·현수막·노점 차양 어디에도. "Merry Christmas"도 글자다.
- 실제 브랜드·캐릭터(산타 얼굴 클로즈업, 유명 캐릭터 장식) 없음.
- 전구 알을 그려 넣지 않기(코드가 깜빡이게 얹음). 그려 넣으면 코드 불빛과 겹친다.
