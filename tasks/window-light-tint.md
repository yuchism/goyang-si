## 지금
- 방 밝기 = 방 자체 밝기 + 창이 주는 빛 × 가중치 — 구조만 있다(`stage.js` `roomDark`, `win.js` `windowLight`).
- `windowLight(d)`는 `{ dark, weight }`만 준다. `weight`는 창이 있으면 늘 1. 방 어둠은 늘 같은 남색, 커튼은 칠 수 없음.

## 먼저 정할 것 (사람 — UX 판단)
- [ ] 색을 얼마나 진하게 (새벽 주황·낮 흰빛·노을·밤 남색·비 오는 날 회색). 지금 남색 밤 화면을 기준으로 "살짝"인지 "확 바뀌게"인지
- [ ] 커튼: 누가 치나(만득 씨 일정 / 강고양이 씨 / 방문자) — 정하지 않으면 이번엔 색만

## 요구사항
- [ ] `windowLight(d)`가 `color`(그 시각·날씨의 빛 색)를 더 준다. 색은 `time.js`의 자연 시간(`daypart`·`twilightGlow`·비)에서만 나온다 (AGENTS.md 6장)
- [ ] 방 어둠·빛을 그 색으로 물들인다. 숫자는 `window.json`(장면 설정)에
- [ ] (커튼을 하기로 하면) 커튼 상태 → `weight`
- [ ] 창이 없는 시험 장면(`check_scene.mjs`)에선 색이 0이어야 한다
- [ ] 확인 (사람): `?dev=1` → 시각을 06:30·12:00·17:50·21:30으로, 「비」 켜고 끄고 → 방 색이 그 시각·날씨처럼 보이는지
- [ ] 회귀: 보이는 동작이 바뀌는 작업이다. `visual_check` 전후에서 달라진 장면을 눈으로 확인하고 적는다. 기준은 승인 후 다시 뽑는다
