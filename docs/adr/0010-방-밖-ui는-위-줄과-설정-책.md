# 0010. 방 밖 UI는 위 줄 하나와 설정 책
- 상태: 채택
- 날짜: 2026-10-22 · 기록: 2026-10-24
- 출처: `MOBILE_PLAN.md` 6·14장

## 맥락
- 폰을 가로로 눕히면 주소창·위아래 줄이 높이를 나눠 가져 방이 오히려 작아졌다. 세로가 더 예뻤다.
- 아래 버튼 줄(책장·소리·켜 두기·전체 화면)이 방 높이를 깎고 있었다.

## 결정
- **위 줄은 남긴다**(고양.시 표시, 만득 씨 상태, 시간, KO/EN, 📖 책장 버튼). 낮은 화면에선 숨기지 않고 방 위에 반투명하게 겹친다.
- **아래 줄은 없앤다.** 소리·켜 두기·전체 화면은 **책장의 "설정" 책** 안으로, 힌트 문구는 뺀다.
- **소리는 기본 켜짐.** 첫 터치 때 조용히 소리를 열고, 설정 책에서 끄면 기억한다.
- 메뉴로 가는 길은 위 줄 📖가 늘 맡는다. 방 안 책장은 "보이면 눌러서 여는 입구"(같은 목록).
- **세로 안내는 없다.**

## 결과
- 방이 화면을 거의 다 쓴다. 설정이 한 번 더 들어가야 보이는 대신 방이 깨끗하다.
- 새 설정·메뉴는 책장의 책으로 더한다(`objects.json` `bookshelf.books`).
- 화면에 안 보이는 접근성 버튼(`aCat`·`aShelf` 등)은 그대로 둔다.
