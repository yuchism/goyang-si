> 상태: **그림 받음·등록함 (2026-10-14).** 33장 모두 받아 `programs.json`에 10개 프로그램으로 넣음. 결과와 검수 메모는 맨 아래 "7. 등록 결과". 2차로 SF 3of3·날씨·누아르·다큐 평소 장면을 다시 그림(같은 날, 7장 끝).
> 관련 문서: `TV_SCHEDULE_PLAN.md` 4-8(순서·길이·방영 조건), `TV_CHANNEL_PLAN.md` 3-3(프로그램 목록)·6장(그림 규격), `TV_STABILITY_PLAN.md`(`programs.json` 형식, 반응 목록)

## 1. 한 줄 요약

새 프로그램 10개(짧은 프로 4 + 일반 6)의 TV 화면 그림 **33장**을 정의한다. 고양이 반응 스프라이트는 새로 그리지 않고 기존 것을 쓴다.

## 2. 공통 규격 (`TV_CHANNEL_PLAN.md` 6장과 같음)

- **320×240, 4:3.** 원본은 크게 그려도 되고(`-source-v1.png`), 납품은 `-320x240-v1.png`.
- 손그림, **굵은 갈색 외곽선**, 색은 적게. 방 안에선 아주 작게 보이므로 **실루엣 + 소품 한두 개**로 장르가 바로 읽히게.
- **글자 없음.** 제목·자막·점수·"칙!" 같은 소리 글자는 모두 코드로 얹는다.
- **실존 인물·방송·회사·상표를 닮게 그리지 않는다.** 로고, 실제 제품 모양, 실제 방송 화면 구성 금지. 패러디는 분위기만.
- 등장 고양이는 강고양이 씨를 닮아도 된다(기존 설정).
- 같은 프로그램의 `loop` 2장은 **구도·선이 겹치게**(번갈아 보여주므로 튀지 않게). 사건 장면은 구도를 바꿔도 된다.
- 아래 화면 1/5은 자막이 올라갈 자리로 너무 복잡하게 채우지 않는다.

**파일 이름** (기존과 같은 방식)
- 원본: `assets/tv/programs/tv-<id>-<n>of<N>-source-v1.png`
- 납품: `assets/tv/programs/tv-<id>-<n>of<N>-320x240-v1.png`
- 웹: `web/r/tv/tv_<id>_<n>of<N>.webp`
- `assets/tv/tv-assets.json`의 `programs`에 `{id, file, kind, size}`로 추가(`kind`: `loop`·`event`·`end`, `size`: `small`·`medium`·`large`).
- 아틀라스: 지금처럼 3×3에 9칸씩 차례로(`tv-screen-atlas-4of7` ~ `7of7`). 단독 생성해도 됨.

## 3. 프로그램별 그림

표기: **L** = 평소(`loop`), **E** = 사건(`event`, 크기 S·M·L), **End** = 프로그램 끝 장면. 자막은 번역 키 안(ko / en).

## 6. 하나 넣을 때마다

1. 그림 → `assets/tv/programs/`, 웹용 → `web/r/tv/`, `tv-assets.json`에 항목 추가
2. `web/r/tv/programs.json`에 프로그램 추가: `name`, `loop`, `events`, `end`, `gap`, `watch`, `titleKind` + 편성용 `runtime`, `short`/`flex`, 방영 조건(4-2), `maxPerDay`
3. 번역 키(`web/js/i18n.js`): 프로그램 이름 + 자막
4. `node tools/check_tv.mjs` 통과, 미리보기 도구 7일 편성표 확인
5. 다음 개편 때 낮잠 정파 줄이기 검토(4-7)

## 8. 고양이 홈쇼핑 (회의 2026-10-14, 그림 받음·등록함)

**목적:** 낮잠 정파 자리(14:00~16:00 근처)를 채워 정파를 줄이거나 없앤다. 뉴스·연예가로 채우면 쏠리므로 낮 시간 전용 프로그램으로.

**구성:** 상품 다섯 가지를 차례로 판다(한 상품 약 24분). 상품마다 그림 2장(평소 장면 둘, 살짝 다르게) = **10장**.

| 순서 | 상품 | 1of2 | 2of2 (살짝 다르게) |

| 1 | 코트·모자 | 모델 고양이가 코트 입고 모자 쓰고 걷기 | 멈춰서 뒤돌아 포즈 |
| 2 | 밥솥 | 모델 고양이가 밥솥을 두 앞발로 들어 보이기 | 뚜껑 열고 김이 모락 |
