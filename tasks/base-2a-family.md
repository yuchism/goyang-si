## 상태 → 연출 (상태 JSON 모양은 `docs/STATUS_JSON.md`)
식구마다 따로 정한다(동시에 여러 일이면 각자 자기 일).
- **강고양이:** `roles.implement`가 busy → 타자 · 아니고 `tasks`에 `relay` → 두루마리를 검수 의자 쪽으로 내밂(2a에선 빈 의자) · `question` → 환기구를 올려다봄(`cat_lookup`) · `ready` → 앉아서 꼬리 탁탁(앉기 두 장을 느리게) · 그 밖 → 식빵·졸기·그루밍을 천천히 번갈아.
- **쥐야쥐 왕** (위가 먼저): `factory.blocked` → 턱 괴기 + 경광등 · `human_review` → 환기구 쪽 귀 기울임(앉기 그림 + 만득 "어디 보자…") · `approval` → 말린 두루마리를 들고 환기구 쪽(만득 "음…") · 그 밖 → 앉기, 일이 하나도 없으면 꾸벅 졸기.
- **금붕생이:** `factory.limit` → 보물상자 닫힘, 금붕생이 한숨 · 아니면 상자 열림, 천천히 헤엄.
- **까치:** `deploy`가 있으면 횃대에 앉아 기다림(앉기·쪼기) · 없으면 횃대 비어 있음.
- **한도 대기**면 강고양이도 졸기(줄 서서 꾸벅은 2b에서 식구가 다 모이면).
- **밤:** 같은 연출, 밤 그림 위(기지 1의 밤 그대로).

### 바뀐 걸 봤을 때 한 번씩 (이 기기에서 지난번 본 상태와 비교 — 기기에만 저장, 없으면 안 함)
- `stats.done`이 늘었으면: 왕이 한 팔 번쩍 → 까치가 천창으로 날아감 (상황판은 원래대로 넘어감).
- 지난번 `approval`이던 일이 줄고 `ready`·그 뒤 단계가 늘었으면: 옥새 쾅 + 펼친 두루마리 잠깐.
- `stats.rejected`가 늘었으면: 왕이 두루마리를 둘둘 말아 던짐(말린 두루마리가 바닥으로).
- 만득 씨 말풍선 글: "음…" / "어디 보자…" / "음… 좋아" (영어: "Hmm…" / "Let's see…" / "Hmm… good"), 거실 말풍선처럼 잠깐 떴다 사라짐.

### 폰 들어올 때
- 스르륵(기지 1)이 멈추는 곳: 강고양이가 타자 중이면 책상, 아니면 왕좌(지금처럼).
