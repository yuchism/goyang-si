## 범위
- **만화방 표지 + 1화 티켓(#13)이 `main`에 합쳐진 뒤에 시작한다** — 같은 만화방 코드(`web/manhwa/shop.js`)를 건드린다.
- 만화방 안(`/manhwa/`)의 계산대 뒤 벽, 나무늘보 사장님 머리 위쪽에 **동그란 벽시계** 하나. 그림 파일 없이 코드로(캔버스든 SVG든 지금 만화방 장면 방식대로).
- **들어올 때 화면 움직임**(아래 결정)도 같이 — 같은 장면 코드라서.
- 다른 장면·사장님 동작·운동 편성은 건드리지 않는다.

## 결정
- **정확한 시계:** 시침·분침이 **만화방의 시각**(낮·밤·운동 편성이 쓰는 그 `now()` — `?dev=1`로 시각을 옮기면 시계도 같이)을 그대로 가리킨다. 초침은 없음(조용한 가게). 장난 없음.
- 모양: 둥근 테, 흰 판, 열두 개 눈금(숫자 없음 — 그림 속 글자 없음 원칙 그대로, 12·3·6·9만 조금 굵게), 먹색 바늘. 만화방 손그림 화풍에 맞게 선을 살짝 두껍게.
- 크기·자리는 바탕 그림(`web/manhwa/shop/bg-day.webp`)의 빈 벽에 맞춘다 — 사장님 머리·관람금지 책장·간판과 겹치지 않게. 자리·크기 숫자는 만화방 장면 설정 한 곳에.
- 밤엔 만화방 밤 조명과 같은 색조(바탕이 밤 그림일 때 시계 판도 살짝 어둡게).
- 동작 줄이기 설정이어도 시계는 맞게 보인다(바늘은 분마다 한 번 옮기면 됨).

### 계산대 안내판 (주인 2026-11-06)
- 사장님 계산대 위에 작은 **세움 안내판**(종이 접은 삼각 팻말이나 아크릴 판 느낌, 코드로): **「← 나가는 길은 저쪽」** / "← Exit's that way". 화살표는 **출입문 쪽**을 가리킨다(장면에서 문이 있는 방향 — 문이 오른쪽이면 → 로).
- 손글씨 글꼴(Gaegu), 살짝 비뚤게. 사장님·시계·책장과 겹치지 않게, 자리는 장면 설정에.
- 누르면 출입문과 같은 일(고양.시로, `/?from=manhwa`)을 해도 되고, 사장님이 느리게 "저…쪽…이…요…"라고만 해도 됨 — **사장님 말풍선으로**(나가는 건 출입문만 — 실수로 나가지 않게).

### 운동 중 팻말 (주인 2026-11-06)
- 밤에 사장님이 운동하러 계산대를 비우면, **비어 있는 계산대 자리**에 작은 팻말 **「운동 중 →」** / "Working out →". 화살표는 그 시각 운동 기구 쪽(운동 공간 방향).
- 손글씨, 안내판과 같은 모양(같은 그리기 코드를 써도 됨). 낮·운동하지 않을 때는 없음. 기구가 바뀌어 옮겨 가는 동안에도 있음.
- 누르면 화면이 운동 공간 쪽으로 스르륵(폰에서) — 사장님을 찾기 쉽게. 데스크톱 넓은 화면이면 사장님이 느리게 "여…기…요…".
- 들어올 때 스르륵(아래)도 밤에 사장님이 운동 중이면 **문 → 운동 중인 사장님**까지.

### 들어올 때 스르륵 (주인 2026-11-06)
- 만화방 안 화면이 장면보다 좁을 때(폰 등 가로 둘러보기가 되는 화면), 들어오면 **출입문 쪽에서 시작해 사장님(계산대)까지 천천히 스르륵 움직여 멈춘다** — 장면이 옆으로 더 있다는 걸 보여 주려고. 약 2.5~3초, 끝에서 부드럽게 느려짐(ease-out).
- 화면이 장면 전체를 담으면(데스크톱 넓은 화면) 움직이지 않는다.
- 움직이는 중에 손님이 화면을 만지거나 스크롤하면 바로 멈추고 손님 손을 따른다.
- 동작 줄이기 설정이면 움직임 없이 사장님 쪽에서 바로 시작.
- 만화 목록에서 「만화방으로」 돌아올 때는 움직이지 않고 사장님 쪽에서(처음 들어올 때만 — 들어온 길 `via`가 약도·지도책·직접일 때).
