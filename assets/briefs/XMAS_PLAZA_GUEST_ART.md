## 2. 5칸

| 칸 | 동작 |
|---|---|
| ① | **걷기 — 왼발 앞 닿기.** 옆모습, **오른쪽을 보고** 걷는다. 앞발(왼발) 뒤꿈치가 바닥, 뒷발은 뒤로 |
| ② | **걷기 — 지나가기.** 두 발이 몸 밑에서 엇갈림, 몸이 살짝 위로 |
| ③ | **걷기 — 오른발 앞 닿기.** ①의 다리를 바꾼 것 |
| ④ | **걷기 — 지나가기.** ②의 다리를 바꾼 것 |
| ⑤ | **트리 올려다보기.** 오른쪽을 보고 서서 고개를 들어 위(오른쪽 위)를 올려다본다. 눈이 동그래지고 입은 살짝 "와". 앞발은 가슴 앞에 모음 |

- ①→②→③→④→① 반복해서 걷는다. **제자리걸음**으로 그린다(앞으로 나가는 건 코드가). 네 칸의 발바닥이 같은 기준선에 닿는다.
- **캥거루·토끼는 깡충 뛰기 한 바퀴:** ① 웅크림(발 바닥) → ② 뛰어오름(발이 기준선 위로 약 40px 뜸, 몸 쭉) → ③ 공중(약 60px) → ④ 내려앉음(발 바닥, 살짝 웅크림). ⑤는 다른 애와 같이 서서 올려다보기.
- 꼬리·귀·목도리 끝은 걸음에 맞춰 조금씩 흔들려도 좋다. 단 **자기 칸 안에서.**
- 왼쪽으로 걷는 그림은 그리지 않는다(코드가 뒤집는다). 그래서 목도리 매듭 같은 건 어느 쪽이어도 어색하지 않게.

## 3. 공통 규격

| 항목 | 값 |
|---|---|
| 시트 | **2560×768 한 장, 가로 5칸(칸마다 512×768)**, 칸 순서 ①~⑤ 왼쪽부터 |
| 배경 | 투명 (후광·흰 테두리 없이) |
| 발 기준선 | **y = 730** (생일 틀과 같음). 걷기 ①~④·⑤의 발바닥이 여기 (깡충 ②③만 예외) |
| 칸 넘침 | 꼬리·귀·목도리 끝까지 **자기 칸 안에** |
| 크기 | 1장 표의 키(발바닥 ~ 머리·귀·모자 꼭대기). 강고양이 씨 = 560 기준. 생일 시트와 같은 키 |
| 화풍 | `GUEST_SPRITE_PLAN.md` 4장 룩앤필 그대로: 진한 갈색 굵은 외곽선, 평평한 색면, 2~3등신, 분홍 포인트 |

**그리지 않는 것 (코드가 한다):** 그림자, 발자국, 내리는 눈, 좌우 반전, 글자.
