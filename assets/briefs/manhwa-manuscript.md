# 원고: 만화방 원고 넣는 법 (manhwa-manuscript)

> 상태: **쓰는 중 (2026-11-06).** 티켓 `tasks/manhwa-viewer.md`. 원고는 주인이 그린다 — 이 문서는 원고 폴더의 README 겸 원고 규격.
> 도구: `tools/build_manhwa.py` (머리 주석이 같은 내용)

## 1. 폴더 (git 무시 — `assets/*`)
```
assets/manhwa/csf/
  cover.png            ← 작품 표지 (있으면 목록 표지·목록 공유 미리보기. 없으면 1화 첫 장)
  1/01.png, 02.png …   ← 1화 원고 (png·jpg). 이름 순서대로 이어 붙는다
  2/01.png …
```
- 표지는 회차 폴더 안이 아니라 작품 폴더에 `cover.png`로. 회차 폴더에 넣으면 원고 한 장으로 들어간다.
- 장 이름은 `01`, `02` …처럼 앞에 0을 붙인다(`10`이 `2`보다 앞에 오지 않게).

## 2. 규격
- 폭은 아무래도 된다(도구가 1080으로 맞춤). 세로는 길어도 된다(약 2000px 조각으로 나눔).
- 위아래 바깥 여백·장 폭 전체를 가로지르는 바깥 테두리는 도구가 잘라낸다. 칸 테두리는 남는다.
- **표지 제목은 맨 위 1/10 밖에.** 뷰어는 위쪽 막대 밑(머리 띠)에서 원고를 시작하지만, 막대가 다시 나올 때 맨 위를 덮고, 썸네일·공유 미리보기는 첫 장 위쪽을 잘라 쓴다.
- 표지(`cover.png`)는 세로 4:5 근처. 목록은 위에서부터 4:5까지 쓰고 아래쪽이 종이색으로 스르르 이어지며 그 위에 연재 제목·버튼이 얹힌다 — 아래 1/3에는 중요한 그림을 두지 않는다. 공유 미리보기(1200×630)는 표지 위쪽을 자른다.
- 그림 안 글자(대사·제목)는 한국어만.

## 3. 올리기
```
python3 tools/build_manhwa.py csf 1 --open 2026-11-20 --title "제목"
python3 tools/build_manhwa.py csf --check
```
